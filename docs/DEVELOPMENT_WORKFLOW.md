# Development Workflow

```text
Select task
  ↓
Read state/spec/skill
  ↓
Inspect existing implementation
  ↓
Plan smallest change
  ↓
Implement
  ↓
Run tests
  ↓
Review SEO/accessibility/performance
  ↓
Update docs/state
  ↓
Commit
  ↓
Handoff
```

## Branches

- main: production
- dev: integration
- feature branches: isolated tasks

## Handoff

Every AI session must leave:

- current state
- completed work
- next task
- unresolved issues
- tests run
