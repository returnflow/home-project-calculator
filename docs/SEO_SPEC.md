# SEO Specification

## Strategy

Target genuine calculator/problem-solving intent. Do not create pages solely for trivial keyword variants.

## Initial URL pattern

```text
/gravel/gravel-calculator
/gravel/pea-gravel-calculator
/gravel/driveway-gravel-calculator
/gravel/gravel-cost-calculator
/gravel/gravel-tonnage-calculator
/gravel/gravel-coverage-calculator
/gravel/river-rock-calculator
/gravel/crushed-stone-calculator
/gravel/crusher-run-calculator
/gravel/french-drain-gravel-calculator
```

## Page architecture

Breadcrumb → H1 → introduction → calculator → results → methodology → formula → worked example → assumptions → buying guidance → mistakes → FAQ → related calculators.

## Metadata

Every indexable page needs:

- unique title
- unique meta description
- canonical
- Open Graph metadata
- stable descriptive URL

## Structured data

Use only schema supported by current Google guidance and accurately represented on-page. Never fabricate ratings, reviews, prices or FAQs.

## Internal linking

Every calculator links to its parent category and several closely related calculators using descriptive anchors.

## Sitemap

Only canonical, indexable, useful URLs.

## Programmatic SEO

Reusable templates are encouraged. Mass production of substantially identical low-value pages is prohibited.

## Search Console feedback loop

Regularly identify:

- high-impression/low-CTR pages
- pages ranking positions 5–20
- emerging queries
- missing calculator intents

Improve existing pages before creating duplicates.
