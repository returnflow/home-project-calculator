# AdSense & Monetization Specification

## Model

Organic traffic → useful calculator → AdSense.

AdSense is a monetization layer, not the product.

## Readiness

Before applying:

- useful site-wide navigation
- original substantive content
- functional calculators
- no placeholder/thin pages
- privacy/legal information
- no deceptive UI
- mobile usability
- technical errors resolved

## Ad placement

Ads must never resemble:

- input fields
- Calculate buttons
- result controls
- navigation
- downloads/print buttons

Do not put ads inside the primary calculation interaction.

Start conservatively and measure before increasing ad density.

## Prohibited behavior

Never:

- click your own ads
- ask users to click ads
- incentivize clicks
- buy suspicious traffic
- use traffic exchanges

## EU considerations

Because the operator may serve EU users, implement an appropriate consent mechanism and verify Google's current consent requirements before launch.

## Revenue planning

A $3 page-RPM planning assumption would require roughly 1M monthly pageviews for $3,000/month. Actual RPM varies significantly by country, device, intent, season, ad demand and implementation.

## Official policies

Re-check Google's current AdSense and publisher policies before monetization.
