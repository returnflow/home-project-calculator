# Prompt 005 — Gravel Calculator

Read PRD, calculation engine spec, SEO spec, accessibility skill and testing skill.

Build the first production calculator using the shared engine.

Inputs:

- shape
- dimensions
- depth
- material
- waste/allowance
- optional price basis

Outputs where applicable:

- area
- volume
- cubic yards
- cubic metres
- weight
- tons
- metric tonnes
- cost
- recommended order quantity

Requirements:

- accessible
- mobile-first
- clear errors
- assumptions visible
- no ads
- no duplicated formulas

Add unit/component/E2E tests.
